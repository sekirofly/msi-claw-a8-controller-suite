# DeckyPlumber 调研与 A8 路线

> 历史设计/研究参考；当前行为和安装说明以 README 为准。

历史调研说明：以下多类型建议已被[当前设计](design.zh-CN.md)取代。产品范围已确定为仅管理 A8 内置手柄、固定 Xbox Elite 输出、不提供虚拟类型选择。

调研日期：2026-11-07。依据为最新拉取的 DeckyPlumber `cebd2fc`（package 0.1.8）和 InputPlumber `6aca920`。完整固定版本源码链接见[英文报告](research.md)。以下是代码调研结论，不代表已在 A8 真机验证。

## 哪些功能值得用

| 功能 | 上游实际实现 | 对 A8 的价值 |
| --- | --- | --- |
| 虚拟手柄类型 | 默认、Xbox Series/Elite、DualSense/Edge、Hori Steam、Steam Deck、8BitDo Ultimate 2；通过 InputPlumber D-Bus 切换 | 高。按机器实际支持的类型显示，不能把列表当成兼容保证。 |
| 按游戏配置 | 每秒检查当前游戏，保存/应用各游戏的手柄类型与映射配置 | 高，但放在手动切换验证之后，避免游戏中突然断开重连。 |
| 输入映射编辑 | 手柄按键/轴/扳机/旋钮、键盘键、鼠标按键/移动；一个源事件可映射到多个目标 | 优先做 M1/M2 和菜单键；多目标映射不等于录制延迟连招。 |
| 映射方案管理 | 新建、编辑、删除、复制、组合方案，合并基础映射，取消选择时恢复基础方案 | 值得借鉴，但要明确冲突优先级并保留基础配置的完整字段。 |
| 内置预设 | 菜单键互换、实验性音量键互换 | 菜单键有用；音量互换优先级低。 |
| 更新、重装、多语言、设备信息 | 上游已有界面 | 沿用我们现有安装校验方案，语言保持中文/英文两种。 |
| 睡眠/唤醒 | 注册了事件，但后端回调仅记日志 | 不能当成已有的唤醒修复功能。 |

上游还有“新游戏配置默认使用 Default 模式”的开关；它只是配置继承规则，不是硬件新功能。

## 不要混淆的三层功能

- **背键硬件模式：**现有插件的 Macro / Combination / Disabled。
- **虚拟手柄类型：**让 Steam/游戏识别为 Xbox、DualSense 等，由 InputPlumber 实现。
- **按键映射：**把实际输入事件映射为其他按键或键鼠事件。

DeckyPlumber 没有我们现有的左右震动强度与三种背键硬件模式控制，恰好可以互补。没有找到完整陀螺仪校准/灵敏度、摇杆/扳机死区调节、定时宏录制、RGB、风扇、功耗管理页面。类型定义里出现 gyro/deadzone 不等于已经做了这些功能。

## A8 有没有基础支持

当前 InputPlumber 上游的 A8 配置匹配 `MS-1T8K`，包含 XInput/DInput、菜单键、背键和陀螺仪/加速度输入，默认输出 Xbox Elite + 鼠标 + 键盘。其映射把 M1/KeyRightBrace 转成 RightPaddle1，M2/KeyLeftBrace 转成 LeftPaddle1。

因此独立背键映射、支持陀螺仪的虚拟类型有研究基础，但你机器安装的版本、内核、固件和当前背键硬件模式可能影响事件是否真正出现。切成 DualSense 不会产生自适应扳机等不存在的硬件能力。

## 不能直接照搬的实现

1. 上游写死 `CompositeDevice0`，新项目应找出真正的 A8 内置设备，避免外接手柄或设备重排后改错对象。
2. 上游能力查询失败时仍展示全部模式；我们应显示检测不可用，不猜支持范围。
3. 上游依靠 `/tmp/.inputplumber.state` 缓存模式，部分错误仅写日志；我们要读实际状态、串行写入并反馈失败。
4. 上游回到默认模式时，在状态文件存在的路径会重启 InputPlumber；我们先保存原始目标设备及配置，验证恢复路径，不把重启服务当作无害操作。
5. 启动时先只读。按游戏自动应用需要显式开启，并处理与 DeckyPlumber 同时自动写配置的冲突。
6. 基础背键/震动控制与 InputPlumber 功能分开：缺少后者时，已有硬件功能仍应可用。
7. 安装后可能需要重启、个别震动异常可能需要 EC 恢复的问题，仍没有通过本次调研解决。

## 开发顺序

1. 移植现有硬件控制，加入只读设备和能力探测。
2. 做手动虚拟手柄切换与恢复原配置，真机验证输入、菜单键、背键、震动及外接手柄共存。
3. 做 A8 背键/菜单键映射，测试其与三个硬件模式的组合。
4. 再做可选的按游戏配置，验证进退游戏、睡眠唤醒、Decky 重载。
5. 陀螺仪控制、摇杆/扳机调节另作实验，不承诺首版提供。
